# Boxplot Shift Lab

一个可以直接发布到 GitHub Pages 的静态网页，用来演示两个 right-skew 箱线图之间的 overlap 和 shift。

## 本地查看

直接在浏览器打开 `index.html` 即可。

## 发布到 GitHub Pages

1. 新建一个 GitHub repository。
2. 上传 `index.html`、`styles.css`、`script.js` 和 `README.md`。
3. 在仓库 Settings -> Pages 中选择 `Deploy from a branch`，branch 选 `main`，folder 选 `/root`。
4. 保存后，GitHub 会生成一个 Pages 网址。
